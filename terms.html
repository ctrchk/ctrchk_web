1.5 嚴格反作弊（Anti-Cheat）與軌跡數據審計條款

為維護低碳出行及全港車手排行榜之嚴肅性、榮譽感與公平秩序，本平台採用實時 GPS 軌跡多因子審計機制：

  • 滑動窗口速檢算法 (Sliding Window Speed Audit)：系統會對用戶提交的 GPX 定位序列進行滾動窗口（Window Size = 5）速度審查。一旦檢測到瞬時時速或區段移動均速超過 45 km/h，該次騎行紀錄將被直接判斷為疑似作弊。
  • CYCTRACK 地圖匹配算法 (Map Matching Coverage)：提交的 GPS 定位軌跡會與緩存的香港政府官方 CYCTRACK GIS 單車徑地理網絡進行 50 米半徑平底匹配（Coverage Filter）。匹配重合率低於 60% 之行程將被自動判斷為汽車、地鐵或非自行車通勤。
  • 作弊處理後果、審查與 7 天 GPX 申訴機制：對於觸發反作弊算法判定之行程，本平台後端機制將會自動暫停該次騎行的 XP 發放、代幣獎勵及里程累積結算，並將該用戶之此項歷史紀錄標記為「待審核作弊（Pending Audit Cheating）」。本平台並不會立即、永久單方面封禁該帳戶，而是給予用戶充分的申訴保障：用戶有權在系統標記作弊之日起 7 個自然日內，透過本平台「回報 Bug/反饋意見」或聯絡信箱提交該行程之原始、未經修改之完整 GPX/FIT 軌跡日誌文件進行人工申訴（GPX Appeal）。若超過 7 日未提出申訴或申訴經核心委員會人工覆核確認作弊無誤，該次紀錄將永久作廢。若用戶多次、惡意蓄意竄改前端代碼、虛構 client_uuid 實施刷單，我們有權無限期暫停其帳戶權限並封禁相關 IP。

二、用戶隱私與個人資料保障條例

我們高度重視您的隱私權與個人敏感資料。本隱私條例旨在向您說明我們如何遵循香港特別行政區法例第486章《個人資料（私隱）條例》之規範，收集、處理、儲存、共享及刪除您的個人資料與高頻精確位置數據。

2.1 精確地理位置數據（Geolocation）收集與後台通訊

  • 收集目的與頻率：當您主動點擊「開始騎行」或「地圖導航」功能時，本平台會請求您的設備授予「精確位置權限 (High Accuracy Geolocation)」。在騎行期間，平台會以高達每 1-3 秒一次的頻率收集您的緯度、經度、精確海拔、方向角及移動速度，並於本地緩存中累積生成包含時間戳之 GPX 歷史軌跡。
  • 後台上傳：當您提交騎行時，上述軌跡數據會以 JSON 加密形式上傳至後端伺服器（存儲於 `cycling_history` 表之 `gpx_track` 欄位），以用於反作弊多因子審核、計算已省車資、更新 Elite Score 因子，以及為您導出專屬 IG Story 海報。
  • 多人房間同步：在多人實時房間運行時，系統會調用 Heartbeat API，每 5 秒一次將您的實時坐標廣播給該房間內的其他成員。一旦您主動退出房間、關閉導航、暫停或結束騎行，上述坐標廣播將立即終止。

2.2 我們收集的個人資料類別

  • 帳戶基本資料：電子郵件地址、姓名、用戶名、頭像、註冊來源（Email 或 Google OAuth）、電子郵件驗證狀態。
  • 高級會員補充資料：聯絡電話（電話號碼）、騎行經驗（如初心者/專家）、主要騎行地區、出生日期、主要使用單車類型（公路車/山地車等）。
  • 技術日誌數據：用戶 IP 地址（包括同意本條款時的 IP 地址）、設備 User Agent 瀏覽器指紋、登入日誌、接口調用歷史、 client_uuid 離線同步識別碼。

2.3 資料存儲、防洩密技術與安全防護

  • 不可逆加密：用戶註冊時設定的密碼在傳輸至後台後，均通過不可逆的 Bcrypt 12輪鹽值加密算法轉為雜湊值存儲。任何管理員、開發人員或外部駭客均無法讀取您的原始密碼。

  • 第三方API整合：本平台整合了 Google OAuth 登入、Gemini AI 騎行狀態教練分析接口、以及 WalletWallet 數字卡面接口。數據在傳遞至上述第三方服務時均經過 SSL/TLS 1.3 高強度加密通道傳輸。
