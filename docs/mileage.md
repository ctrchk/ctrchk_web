## 1. 願景 (Vision)

### 1.1 里程計劃的本質與存在意義
在主流城市規劃與大眾交通認知中，單車長期被邊緣化為「休閒娛樂」或「體育競技」工具。**城市運輸單車**的存在，是為了解決這個長達數十年的結構性痛點，讓單車回歸城市交通主導，推動「城市運輸騎行 (Transportation Cycling)」的範式轉移。

而在這個範式轉移中，**里程計劃 (Mileage Program)** 並非一個附屬的行銷工具，它是整個**城市運輸單車**作業系統的**「身份認同核心 (Identity Engine)」**。

我們不販賣折扣，我們也不提供廉價的金融補貼。我們深知，透過持續性的現金折抵或實體贈品吸引來的用戶，會在補貼停止的瞬間流失。**城市運輸單車里程計劃賣的是身份、成就、社會認同、自我實現與長期習慣的自我催化。**

```
┌──────────────────────────────────────────────────────────────────┐
│                   城市運輸單車「多巴胺與身份」雙螺旋動力                 │
├────────────────────────────────┬─────────────────────────────────┤
│       多巴胺螺旋 (Dopamine)     │        身份認同螺旋 (Identity)  │
├────────────────────────────────┼─────────────────────────────────┤
│  - 騎行結束解鎖隨機盲盒 (Coins) │  - 錢包中的 WalletWallet 專屬卡面 │
│  - 每日通勤連勝紀錄 (Streak)    │  - 領袖級的 Black Gold 極致高對比  │
│  - 3D 實體質感徽章 360 度旋轉   │  - 專屬 Discord / 討論區金卡頭像框│
└────────────────────────────────┴─────────────────────────────────┘
```

### 1.2 為什麼與傳統航空/飯店忠誠度計劃不同？
傳統航空或飯店忠誠度計劃（如國泰會員、萬豪旅享家）本質上是**「消費驅動型 (Spend-Driven)」**。用戶獲得高等級的唯一途徑是高額消費（購買商務艙機票、入住奢華套房）。這會導致：
* **階級固化**：無高預算的普通用戶被完全排除在生態權益之外。
* **高昂運營成本**：免費機票、行政酒廊、客房升等需要平台或合作夥伴承擔巨大的邊際成本。

而**城市運輸單車里程計劃**是**「行為與認同驅動型 (Behavior & Identity-Driven)」**。
1. **零邊際成本特權**：我們的權益核心是軟體功能解鎖（例如 3D 地圖、高級分析、AI Summary、專屬主題、社群身份組）。不論會員數量從 100 人增長到 100,000 人，平台的邊際發行成本趨近於零。
2. **汗水累積的自豪感**：金卡會員不能用錢買到，必須由騎士在烈日下、在港島或將軍澳的單車徑上，一公里一公里、踏踏實實踩出來。這種由「自身汗水與意志」鑄造的卡級，其精神壁壘和忠誠度遠非單純花錢獲得的航空卡可比。

### 1.3 如何創造極致的長期參與度 (Long-Term Engagement)
我們利用**「365天滾動保級機制」**打破了傳統「自然年結算」帶來的下半年疲態。在傳統自然年系統下，用戶若在 6 月已完成保級，下半年將失去騎行動力；或若在 10 月發現保級無望，便會直接放棄。

城市運輸單車採用**「按天滾動 (Rolling 365 Days)」**：
* 騎士今天看到的「累積里程」，是今天起往前倒推 365 天之內的總和。
* 每一天，一年前的那一天的里程就會失效。這創造了一種溫和、持續的「保級引力」。
* 搭配我們獨創的「里程過期壓力測試圖表」，騎士能清晰預知未來 30 天即將扣除的里程，從而將「被動保級」轉化為「主動維持騎行習慣」的遊戲化樂趣。

## 2. 設計哲學 (Design Philosophy)

為了確保系統在極低運營成本下發揮最大效能，我們制定了八大核心設計哲學：

```
                    ┌──────────────────────────────┐
                    │      里程計劃八大哲學矩陣       │
                    └──────────────┬───────────────┘
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
   [ 身份高於折扣 ]          [ 認可重於贈品 ]          [ 長期進階機制 ]
   不打價格戰，用尊榮感      拒絕實體垃圾，提供        利用滾動里程，建立
   與高難度卡級建立壁壘      極致的數位榮譽與徽章      一生的騎行生活軌跡
         │                         │                         │
         ├─────────────────────────┼─────────────────────────┤
         ▼                         ▼                         ▼
   [ 數位優先權益 ]          [ 零邊際成本生態 ]        [ 低運作維護成本 ]
   所有解鎖皆在軟體端，      以軟體功能作為福利，      API 自動化，無人工
   如 Mapbox 3D 與黑金主題   實現無限規模化擴張        審核與倉儲配送負擔
         │                         │                         │
         └─────────────────────────┼─────────────────────────┘
                                   ▼
                       ┌───────────────────────┐
                       │   [ 汗水與成就驅動 ]  │
                       │   拒絕付費直接買卡，  │
                       │   唯有騎行才是硬道理  │
                       └───────────────────────┘
```

* **身份高於折扣 (Identity Over Discounts)**：
  不要試圖用 $5 港元的租車券去討好車手。相反，給予他們在 Apple Wallet 錢包裡一張閃耀著黑金光芒的實體級質感卡片，以及在地圖上獨一無二的「動態風馳尾跡 (Aero Tail Effect)」。車手會為了這份社會認同，向身邊的朋友瘋狂宣傳。
* **認可重於贈品 (Recognition Over Giveaways)**：
  實體水壺、騎行手套等贈品會迅速變成垃圾，且伴隨著高昂的物流與採購成本。我們提供的是「3D 虛擬金屬徽章（WebGL 渲染）」與「週年殿堂紀念章 (Legacy Crest)」，讓認可留在車手的數字牆上，永久保存，隨時分享。
* **長期進階機制 (Long-Term Progression)**：
  設計一條長達數年的成長曲線。從「銅卡探索者」到「金卡破風精英」，每一個卡級都有深思熟慮的階梯。即使達到最高卡級，還有「Elite Score (精英積分)」與「季節限定挑戰」讓騎士持續追求。
* **數位優先權益 (Digital-First Rewards)**：
  我們所有的核心特權（如 Mapbox 3D 車道級導航、CYCPARKSPACE 動態泊位圖層、AI 騎行日誌生成）全部是代碼實現。這保證了特權的即時交付與高科技感。
* **零邊際成本生態 (Sustainable Ecosystem)**：
  不依賴任何外部財政補貼。當會員數量從 1,000 人規模化擴充至 1,000,000 人時，伺服器解析 JWT、調用 WalletWallet API、以及渲染前端主題的邊際成本接近於零，實現真正的財務自適應與可持續發展。
* **低運作維護成本 (Low Operational Cost)**：
  拒絕人工審核，拒絕人工客服。卡級晉升、保級扣除、Wallet 卡包更新、3D 徽章發放全部由後端 `api/user.js`、`api/getHistory.js` 與 cron 任務自動觸發。
* **汗水與成就驅動 (Achievement-Based)**：
  我們嚴厲拒絕「付費升級」或「聯名卡直接送金卡」的捷徑。如果一個金卡身份可以用錢買到，那麼金卡騎士在地圖上的尊榮感將瞬間歸零。

## 3. 會員架構 (Membership Structure)

我們重新設計了**城市運輸單車**的三大核心會員卡級。每一個卡級都擁有獨特的生命力、視覺語言與人格特徵：

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │                      城市運輸單車 會員卡級光譜                          │
 ├───────────────────┬────────────────────┬───────────────────────┤
 │   銅卡 (Bronze)   │    銀卡 (Silver)   │      金卡 (Gold)      │
 ├───────────────────┼────────────────────┼───────────────────────┤
 │  - 探索者 (0km+)  │  - 風行者 (150km+) │   - 破風精英 (500km+) │
 │  - 森林與泥土綠   │  - 科技與機械銀灰  │   - 奢華極致黑金      │
 │  - 探索、建立習慣 │  - 通勤便利、高頻  │   - 領袖、極致、安全  │
 └───────────────────┴────────────────────┴───────────────────────┘
```

---

### 3.1 銅卡 (Bronze) — 探索者 (Explorer)

* **定位與宗旨**：
  這是車友踏入**城市運輸單車**生態的起點。它的使命是「消除焦慮、建立習慣」。在這個卡級，我們不給予車手任何行駛里程的壓力，而是專注於陪伴他們安全騎完第一公里。
* **目標用戶群**：
  新晉騎士、週末休閒騎行者、偶爾踩共享單車通勤的市民。
* **視覺與主題語言**：
  * **主題色**：森林與泥土綠 (Forest Clay, `#D8A56B` / `#1B3B2B`)。
  * **卡面質感**：磨砂啞光銅 (Matte Bronze)，邊框帶有溫和的有機紋理。
* **人格特徵 (Personality)**：
  好奇、熱情、無壓力、正在探索城市脈絡的初心者。
* **保級與晉升**：
  * **晉升**：0 km 起自動獲得。
  * **保級**：終身免降級。

---

### 3.2 銀卡 (Silver) — 風行者 (Rider)

* **定位與宗旨**：
  這是**城市運輸單車**的中堅力量。銀卡騎士是這座城市的「日常通勤動脈」。他們不再滿足於簡單的休閒，而是將單車深度融入生活。我們的特權設計側重於「提高通勤效率、保障泊車安全與基礎社群互助」。
* **目標用戶群**：
  每日通勤白領、高頻單車使用者、大學生、熱衷週末長途穿梭的愛好者。
* **視覺與主題語言**：
  * **主題色**：科技與機械銀灰 (Mechanical Chrome, `#D1D9DF` / `#3A4B5C`)。
  * **卡面質感**：拉絲金屬鈦銀 (Brushed Titanium)，帶有微弱的藍色偏光，代表速度與機械美學。
* **人格特徵 (Personality)**：
  高效、敏捷、注重實用性、將騎行視為生活態度的城市風行者。
* **保級與晉升**：
  * **晉升**：近 365 天累積里程達 $150\text{ km}$。
  * **保級**：滾動 365 天里程保持在 $120\text{ km}$ 以上。

---

### 3.3 金卡 (Gold) — 破風精英 (Elite)

* **定位與宗旨**：
  這是整個**城市運輸單車**生態系統的最高榮譽。金卡會員是我們的核心護城河、品牌佈道者與精神圖騰。他們的特權是「極致的安全護航、無與倫比的 3D 霓虹視覺、以及無上的社群權力」。
* **目標用戶群**：
  年累積里程極高的重度硬核車手、全天候通勤戰士、挑戰賽狂熱征服者。
* **視覺與主題語言**：
  * **主題色**：奢華極致黑金 (Obsidian Gold, `#F0D372` / `#000000`)。
  * **卡面質感**：黑曜石鏡面配合液態流光金 (Liquid Obsidian & Mirror Gold)。
  * **特別設計**：在 standalone PWA 模式下，全站主要的 CTA、啟動按鈕強制覆寫為**黑底金字**（高對比度黃金模式），確保在刺眼的戶外陽光直射下，螢幕內容依然 100% 安全可讀。
* **人格特徵 (Personality)**：
  領袖氣質、追求極致、風雨無阻、對單車文化有極致熱愛的硬核風範。
* **保級與晉升**：
  * **晉升**：近 365 天累積里程達 $500\text{ km}$。
  * **保級**：滾動 365 天里程保持在 $400\text{ km}$ 以上。

### 4.1 特權詳細說明 (Features in Detail)

#### A. 身份認同 (Identity)

##### 1. WalletWallet 專屬卡面
* **實現原理**：透過後端發起對 WalletWallet API 的安全調用，將用戶等級、名字、當前里程動態寫入 Pass 模板中。
* **UX 體驗**：
  * **金卡**：採用極致高貴的 `#F0D372` 金色背板，背板右下角帶有微幅凹凸質感的 城市運輸單車 徽標。
  * **銀卡**：採用極具科技冷冽感的 `#D1D9DF` 鈦銀色。
  * **銅卡**：採用古樸典雅的 `#D8A56B` 銅褐色。
  當用戶在 iPhone 雙擊電源鍵喚醒 Apple Wallet 時，這張卡片將成為他們在現實生活中的「低碳通行證」。

##### 2. 專屬動態頭像框 (Animated Profile Frames)
* **UX 體驗**：
  * 銀卡用戶在 dashboard.html 和論壇中的頭像外圍會環繞一圈極細的、順時針緩緩旋轉的鈦銀色光暈（CSS 實現，性能消耗極低，無 reflow 隱患）。
  * 金卡用戶的頭像框則升級為「3D流金黑曜石框」，黑色的底框上不規則地劃過暗金色流光。
* **開發者備註**：
  為了保證 PWA 的流暢度與省電性，所有的頭像框動畫一律使用 `transform: rotate` 與 `background-position` GPU 加速，嚴禁使用 JS 逐幀計算。

##### 3. 特殊名字色彩 (Special Name Colours)
* **UX 體驗**：在討論區、多人房和排行榜中，金卡用戶的名字顯示為漸變金色（`linear-gradient(45deg, #f39c12, #f1c40f)`），並帶有輕微的文字陰影，使其從大片白色/灰色字體中脫穎而出。

##### 1. Mapbox GL 3D 導航 (僅限金卡)
* **功能描述**：
  為金卡會員量身定制的極致視覺與安全體驗。當金卡用戶在 `nav.html` 啟動導航時，地圖自動切換為高精度 Mapbox GL 3D 視角。
  * 3D 摩天大樓隨着用戶的行進缓缓後退。
  * 導航線路渲染為一條帶有「呼吸發光效果」的霓虹青色 3D 管道（Neon Cyan Tube）。
  * 當車速大於 $15\text{ km/h}$ 時，3D 霓虹管道會產生向前的流光特效，帶給騎士如同駕駛科幻飛船的感官體驗。
* **安全原因**：

## 6. 成長與晉升體系 (Progression System)

為了打破「單純依靠里程」帶來的枯燥與不公平（例如，大體重騎士、大風天騎行、爬升極高的山路騎士，其體力消耗遠高於平地，但里程數相同），我們引入了革命性的 **「Elite Score (精英評分)」** 系統。

```
                    ┌──────────────────────────────┐
                    │      Elite Score 評分算法     │
                    └──────────────┬───────────────┘
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
   [ 里程因子 (M) ]          [ 爬升因子 (E) ]          [ 頻次因子 (C) ]
   基礎公里數 $\times 10$     累計垂直爬升米數 / 5      30天內 active 騎行天數
         │                         │                         │
         ├─────────────────────────┼─────────────────────────┤
         ▼                         ▼                         ▼
   [ 連勝因子 (S) ]          [ 探索因子 (X) ]          [ 貢獻因子 (P) ]
   目前通勤連勝天數 $\times 5$  新路線/置灰路網解鎖比例    討論區與路況舉報加分
         │                         │                         │
         └─────────────────────────┴─────────────────────────┘
                                   ▼
                       ┌───────────────────────┐
                       │   Elite Score 總分    │
                       │   $M + E + C + S + X + P$ │
                       └───────────────────────┘
```

### 6.1 Elite Score 算法架構
Elite Score 是一個綜合考量體能、毅力、探索度與社群貢獻的加權指數。公式定義如下：

$$\text{Elite Score} = \mathbf{M} + \mathbf{E} + \mathbf{C} + \mathbf{S} + \mathbf{X} + \mathbf{P}$$

* **1. 里程因子 ($\mathbf{M}$ — Mileage)**：
  $$\mathbf{M} = \text{近 30 天累積里程 (km)} \times 10$$
* **2. 爬升因子 ($\mathbf{E}$ — Elevation)**：
  $$\mathbf{E} = \frac{\text{近 30 天累計垂直爬升 (m)}}{5}$$
  * *設計意圖*：致敬征服香港陡峭山路（如柴灣斜、飛鵝山）的硬核騎士。
* **3. 頻次與規律因子 ($\mathbf{C}$ — Consistency)**：
  $$\mathbf{C} = \text{近 30 天內有 active 騎行的天數} \times 15$$
  * *設計意圖*：鼓勵高頻通勤，即使每天只踩 $2\text{ km}$ 的地鐵接駁，也能獲得極高的 Consistency 評分。
* **4. 連勝因子 ($\mathbf{S}$ — Streak)**：
  $$\mathbf{S} = \text{當前通勤連勝天數 (Streak)} \times 5 \quad (\text{上限 } 150\text{ 分})$$
* **5. 探索因子 ($\mathbf{X}$ — Exploration)**：
  $$\mathbf{X} = \text{本市已解鎖單車徑網絡比例} \times 200$$
  * *設計意圖*：激勵用戶走不同的路，解鎖地圖上的「置灰未征服路網」。
* **6. 社群貢獻因子 ($\mathbf{P}$ — Participation)**：
  $$\mathbf{P} = (\text{通過審核的路況舉報件數} + \text{高讚網誌發文數}) \times 20$$

## 11. 設計原理與用戶心理學 (Design & Psychological Principles)

城市運輸單車里程計劃的每一項功能，都有深厚的人類行為心理學底蘊支持。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        里程計劃設計原理與心理學對照                      │
├───────────────────┬────────────────────┬───────────────────────┤
│    特權與功能     │     心理學原理     │       核心效果        |
├───────────────────┼────────────────────┼───────────────────────┤
│ 365天滾動保級     │ 損失規避 (Loss)    │ 克服下半年懈怠，日日保級│
│ 通勤連勝 (Streak) │ 稟賦效應 (Endow)   │ 建立雷打不動的通勤習慣 │
│ 騎行結束隨機盲盒  │ 變動比例強化 (Var)  │ 提升結算時的多巴胺期待 │
│ Apple Wallet 卡包 │ 社會認同 (Social)  │ 自發發卡截圖，低成本傳播│
└───────────────────┴────────────────────┴───────────────────────┘
```

* **1. 損失規避與 365 天滾動里程 (Loss Aversion)**：
  心理學研究表明，人類「害怕失去」的痛苦程度大約是「得到」的兩倍。傳統的年終清零會讓用戶在第四季度擺爛。
  而滾動里程意味著：**「如果你今天不踩單車，一年前你冒著大雨騎的那 15 公里將在明天永遠離你而去。」**
  這種輕微的「失去痛感」會源源不斷地催化騎士推車出門，保持運動習慣。
* **2. 稟賦效應與通勤連勝 (Endowment Effect)**：
  當用戶連續通勤 14 天時，他們會對這「14 天連勝」的數字產生極高的自我擁有感。他們甚至願意在下雨天也穿上雨衣堅持踩單車，僅僅是為了不讓這個數字清零。而我們提供的「100 里程幣修復連勝」則是一個完美的緩衝阀，既回收了里程幣（控制通貨膨脹），又維護了他們的勞動成果。
* **3. 變動比例強化與隨機盲盒 (Variable Ratio Reinforcement)**：
  這是斯金納箱 (Skinner Box) 的核心原理，也是老虎機讓人上癮的原因。如果每次騎行完，系統都給予固定 5 個硬幣，用戶會迅速感到無趣。
  我們改為：**每次結算，有機率彈出「多巴胺盲盒」，隨機開出 $1\sim50\text{ Coins}$ 或「今日雙倍里程卡」**。騎士在捏下剎車、點擊結束的瞬間，大腦會分泌大量多巴胺，期待這一次盲盒的開箱結果。
* **4. 社會認同與 Wallet 虛擬卡片 (Social Proof & Identity)**：
  一張只能在 App 內部查看的電子等級，其傳播半徑極其有限。但當這張卡片能夠無縫常駐於手機系統級的 Wallet 錢包，並在鎖屏狀態下優雅展示時，它便融入了騎士的現實生活圈。騎士在線下與朋友聚會、買咖啡付款時，Wallet 亮出的黑金 CTRC 卡片將成為最自然的談資。

## 13. 未來挑戰與懸而未決的決定 (Future Questions & Open Decisions)

在未來的迭代中，設計委員會與高階 AI 代理必須共同面對並解決以下核心問題：

* **1. 關於「E-Bikes (電動輔助單車)」的界定問題**：
  目前香港法例對電動輔助單車的合法化仍在探討中。
  * *開放決定*：未來是否允許 E-Bike 用戶參與標準里程排行榜？如果允許，是否需要施加一項 $\times 0.6$ 的里程衰減因子，以維護純人力自行車車手的體力尊嚴？
* **2. 滾動扣除在極端暴雨/颱風月（如9月）的代補機制**：
  香港 9 月經常遭遇超強颱風（如山竹、蘇拉）或世紀暴雨，導致全月幾乎無法騎行。這會導致次年 9 月，用戶的滾動里程出現斷崖式下跌，引發大規模集體降級恐慌。
  * *開放決定*：系統是否需要引入一項「天災豁免機制 (Force Majeure Buffer)」？當天文台發出 8 號風球或黑色暴雨警告時，當日全港用戶的里程過期自動凍結並順延 1 天。
* **3. 跨區里程折算係數 (Topographic Factor)**：
  港島區（如柴灣、薄扶林）地形起伏極大，而將軍澳與新界北部（如沙田、大埔）極其平坦。在港島騎行 $10\text{ km}$ 的體力消耗是平地的 3 倍。
  * *開放決定*：是否需要根據 GPX 軌跡的垂直攀升高度，動態折算「等效里程 (Equivalent Mileage)」？例如：爬升 $100\text{ m}$ 等效於增加 $1.5\text{ km}$ 里程。

## 15. 舊系統遷移計劃 (Migration Plan)

為了保障老用戶的歷史數據在升級到 v3.0.0 過程中不受損失，我們制定了以下遷移方案：

* **1. 軌跡格式相容性緩衝 (Backward Compatibility)**：
  老系統中的軌跡有些儲存為原始 GeoJSON 字串，有些則是經緯度二維陣列。新版 `api/getHistory.js` 在讀取 `gpx_track` 時，必須包含一段 `try-parse` 容錯函數：
  ```javascript
  function normalizeTrack(trackData) {
      if (!trackData) return [];
      try {
          if (typeof trackData === 'string') {
              const parsed = JSON.parse(trackData);
              if (parsed.type === 'FeatureCollection') {
                  // 解析 GeoJSON
                  return parsed.features[0].geometry.coordinates.map(pt => [pt[1], pt[0]]);
              }
              return parsed;
          }
          return trackData;
      } catch (e) {
          console.error("軌跡格式解析異常:", e);
          return [];
      }
  }
  ```
* **2. 歷史里程滾動初始化 (Rolling Reset)**：
  在系統升級當日，後端不採用「一刀切」清空。我們將執行一次 migration 腳本，掃描用戶過去一年的所有 `ride_history`，自動為每位用戶計算出「升級當日的近 365 天累積里程」，並將對應的卡級（金/銀/銅）寫入 `user_game_profile`。
* **3. 歷史 Wallet 卡包無縫重簽 (Wallet Re-issue)**：
  老用戶原有的 Wallet 卡包在下次打開 `mileage.html` 時，系統會自動在背景檢測卡級變更。若老用戶已達銀卡，後端會向 WalletWallet 發起 `PUT` 請求更新其 serial，使用戶在打開 Apple Wallet 時，舊卡面在無感狀態下自動蛻變為亮麗的新版鈦銀拉絲卡面。

## 16. 附錄與名詞表 (Appendix & Glossary)

* **城市運輸單車 (City Transport Cycling)**：本平台的官方名稱，代表讓單車回歸城市主流綠色運輸的產品宗旨。
* **WalletWallet API**：一個第三方零收費、提供 Apple 與 Google 錢包生成與分發的極簡數位卡包對接通道。
* **365 天滾動里程 (Rolling Mileage)**：基於當前時間往前倒推 365 日計算的累積里程，每日動態扣除過期的一年前里程。
* **Elite Score (精英評分)**：綜合考量里程、海拔、通勤頻次、連勝度、地圖探索比例等多個維度得出的騎士綜合實力指數。
* **CYCPARKSPACE**：香港合法單車泊車位數據集，在系統中進行實時地圖渲染與導航引導。
* **Ramp (坡道)**：單車手推車天橋或地下通道專用的手推斜面，是導航拓撲中避免騎士扛車上下樓梯的重要因子。
* **黑金高對比度黃金模式**：針對金卡騎士在極端烈日強光直射下，將全站交互按鈕覆寫為黑底金字的高飽和、安全易讀視覺。
